# Contributing

Thanks for your interest in Babylonian Hours.

This is an **educational project**: a clock that explains how the ancient
Babylonians reckoned time in seasonal hours, aimed at students, educators, and
museum or classroom use. Please keep contributions in that spirit — clear,
accurate, and accessible. Historical or astronomical claims should be citable
(see the *Further reading* panel in the app), and changes should serve the
teaching goal rather than add unrelated features.

## Development

    npm install
    npm run build        # bundle src/ into dist/index.html
    npm test             # unit tests (Vitest)
    npm run lint         # ESLint
    npm run format       # Prettier (write)

Then open `dist/index.html`, or serve `dist/` (see the README).

## Project layout

- `src/astronomy.js` — sunrise/sunset math (pure, tested)
- `src/babylon.js` — seasonal-hour conversion (pure, tested)
- `src/capitals.js` — bundled capital location data
- `src/main.js` — view and interaction
- `src/styles.css`, `src/template.html` — styles and the HTML shell
- `build.mjs` — bundles the above into `dist/index.html`
- `test/` — Vitest suites

`index.html` is generated by the build and is **not** committed. Edit `src/` and
run `npm run build`; CI builds and deploys the result.

## Before opening a pull request

- `npm run lint`, `npm run format:check`, and `npm test` all pass.
- Add or update tests for any change to the astronomy or Babylonian math — those
  modules are pure and easy to test.
- Keep the change focused, and say what it does and why.
